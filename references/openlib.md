# CQU-openlib 检索细则

站点：`https://cqu-openlib.cn` — 重大学生共建的资源站，以学业资料、经验分享为主。

---

## 一、什么时候检索

触发：

- 培养方案、课程体系、学分构成
- 转专业（条件、名额、时间、经验帖）
- 往年试卷、真题、复习资料
- 课程资料、教材、网课推荐
- 社团详情、招新信息
- SRTP、大创、科研训练
- 竞赛（数模、大英、程序设计、专业竞赛等）攻略
- 选课细则、给分、考核方式

不触发：

- 食堂在哪、快递在哪、怎么办校园卡 → 本地 `campus.md`
- 作息、熬夜、失眠 → 本地 `wellness.md`
- 用户没提学业问题 → **不要主动打开网站**

## 二、常用关键词表（站内搜索用）

| 用户说法 | 检索关键词 |
|---|---|
| 培养方案 / 学分 | `培养方案`、`学分`、`课程体系` + 学院名 |
| 转专业 | `转专业`、`转专业 条件`、`转专业 名额` + 目标学院 |
| 往年题 | `真题`、`期末`、`往年` + 课程名 + 老师姓 |
| 课程资料 | 课程名 + `笔记` / `资料` / `复习` |
| 社团 | 社团名、`社团`、`招新` |
| SRTP / 科研 | `SRTP`、`大创`、`科研训练` |
| 竞赛 | `数模`、`数学建模`、`大英赛`、`蓝桥`、具体赛事名 |
| 选课 | `选课`、`给分`、`水课`、`考核` |

检索时把**学院名、课程名、老师姓**带上，命中率明显更高。

## 三、读取方式（关键）

1. 先拿搜索结果页，找到目标页面的 URL。
2. **优先在 URL 后加 `.md` 再读一次**，例如 `https://cqu-openlib.cn/xxx` → `https://cqu-openlib.cn/xxx.md`。该站支持这个后缀返回纯净 Markdown，去掉导航和脚本，token 消耗小、信息密度高。
3. `.md` 请求成功 → 直接读该文本。
4. `.md` 404 或返回空 → 退回原页面读正文，忽略导航、页脚、评论区。
5. 页面很长时只读相关小节，不要整页灌进上下文。

## 四、浏览器操作约束

- 域名固定为 `cqu-openlib.cn`。`cqu-openlib.cc`、`cquopenlib.com` 等近似域名**都不是本站**，不要凭记忆拼链接，一律从站内搜索点进去。
- 当前环境若有 `agent-browser` 技能，优先加载并按它说明操作；若没有，改用网页抓取工具直接请求 URL（`.md` 后缀优先，往往无需浏览器渲染）。
- **禁止反复刷新同一页面**。一次未命中 → 换关键词再搜一次 → 仍无结果就停。
- 整个过程最多两轮检索、读取不超过 3 个页面，除非用户明确要求深挖。
- 不在页面里点击无关链接、不填写任何表单、不登录。

## 五、答案组织格式

结论先行，短：

```
<一句话结论>

- 要点 1
- 要点 2
- 要点 3（含时间 / 材料 / 资格等硬条件）

资料来源：[页面标题](https://cqu-openlib.cn/xxx)
```

要求：

- 用自己的话压缩，**不整段粘贴原文**。
- 时间、材料、资格这类硬信息单独拎出来，别埋在段落里。
- 站内信息若是学生个人经验贴，要标明"这是同学经验分享，具体以学院官方通知为准"。
- 多条来源时列出 2–3 个即可，不必全列。

## 六、检索失败的处理

如实说，不要编：

> 在 CQU-openlib 暂时没有查到相关资料，你可以咨询辅导员或者对应任课老师。

可补一句方向（不要变成"你去查"）：

> 这类信息一般学院教务那边最准，我可以先帮你把要问的问题整理清楚。
